# Slide Saver: SlideShare downloader

A small web app that downloads public SlideShare presentations as:

- **PDF**: one page per slide, at the largest image size SlideShare offers (usually 2048 px wide)
- **PowerPoint (.pptx)**: one full-bleed picture per slide, with the deck's aspect ratio
- **Images (.zip)**: `slide-001.jpg`, `slide-002.jpg`, …
- **Single slides**: a "Save this slide" link under every preview

Paste a link, preview every slide, untick the ones you don't want, then download.

## Run it

Requires Node.js 18.17 or newer.

```bash
npm install
npm start            # http://localhost:3000  (PORT and HOST env vars are honoured)
```

## How it works

```
browser ──POST /api/slides {url}──▶ server ──GET page──▶ www.slideshare.net
        ◀── title + slide list ────        (parse slide image URLs)
browser ──GET /api/download?url&format&slides──▶ server ──GET images──▶ image.slidesharecdn.com
        ◀── PDF / PPTX / ZIP ───────────────────        (build file)
```

`src/slideshare.js` finds the slides in a SlideShare page in two ways:

1. **Page data.** Current SlideShare pages are Next.js apps. Their `<script id="__NEXT_DATA__">` holds the
   deck's `totalSlides` and the image descriptor `{ host, imageLocation, title, imageSizes }`. Every
   slide URL is built from that descriptor:
   `https://image.slidesharecdn.com/<imageLocation>/<quality>/<title>-<n>-<width>.jpg`.
2. **HTML scan (fallback).** Slide image URLs are collected from `src`, `srcset`, `data-full` and escaped
   JSON, then grouped per deck, so "related presentations" are ignored. The largest JPEG/PNG is kept
   for each slide. Slides that were lazy-loaded and missing from the HTML are filled in from the URL
   pattern when the page states the total.

`src/builders.js` downloads the images six at a time and builds the file with
[pdf-lib](https://pdf-lib.js.org/), [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) or
[JSZip](https://stuk.github.io/jszip/). If a slide only comes as WebP, the `.jpg` version is fetched
instead, because PDF and PowerPoint can't embed WebP.

### API

| Method & path | Parameters | Returns |
| --- | --- | --- |
| `POST /api/slides` | JSON `{ "url": "<slideshare link>" }` | `{ url, title, totalSlides, slides: [{ number, thumb, full, download }] }` |
| `GET /api/download` | `url`, `format` = `pdf` \| `pptx` \| `zip`, optional `slides` = `1,3,5-8` | the file as an attachment |
| `GET /api/image` | `src` = slidesharecdn.com image URL, optional `download=1&name=` | the image |
| `GET /healthz` | | `{ ok: true }` |

Errors come back as `{ "error": "<message for the user>", "code": "<machine code>" }` with a matching
HTTP status.

### Safety limits

- The server only fetches from `*.slideshare.net` (pages) and `*.slidesharecdn.com` (images). Every
  redirect hop is checked again, so the API can't be used to reach other hosts (SSRF).
- Limits: 20 s timeout per request, 8 MB per page, 15 MB per image, 300 MB per download, 500 slides per
  deck, 3 files built at once, 60 API requests per minute per IP.
- Parsed decks are cached in memory for 15 minutes, so previewing and then downloading only fetches the
  page once.
- The pages are served with a strict Content-Security-Policy, `nosniff` and `X-Frame-Options: DENY`.

When running behind a reverse proxy on another machine, set Express's `trust proxy` in `src/app.js`
to match it, so rate limiting sees the real client IP.

## Tests

```bash
npm test             # unit + API tests (no network needed)
npm run test:e2e     # browser test with Playwright + Chromium
```

The tests never touch the internet. `test/helpers.js` stands in for slideshare.net and slidesharecdn.com
using fixtures in `test/fixtures/`:

- `next-data.html`: the current Next.js page layout, with a related deck mixed in
- `html-only.html`: no page data; slides in `srcset`, escaped JSON and lazy-loaded
- `legacy.html`: the older `data-full` / `data-normal` layout
- `profile-page.html`: a profile listing several decks, which must be rejected
- `images/`: slide images generated by `make-images.py`

## Notes

- Only public presentations work. Private or deleted decks get a clear error message.
- SlideShare can change its page markup at any time. If downloads stop working, save a current
  presentation page as a new fixture and adjust `src/slideshare.js` until the tests pass again.
- Only download presentations you have the right to use, and respect the author's copyright and license.
  This project is not affiliated with SlideShare or Scribd.
